# 01 — Ejercicio 3: base de datos inicial

Este es el ejercicio original de la asignatura. **No procede de los repositorios públicos** citados en las otras carpetas.

- `ejercicio3_bd.pl`: 15 tablas relacionadas por identificadores; cada tabla tiene un mínimo de 70 hechos.
- `consultas_ejercicio3.txt`: 2 consultas para cada una de las 15 tablas (30 en total) y 2 consultas generales adicionales.
- `explicacion_consultas_ejercicio3.txt`: instrucciones y explicaciones.

Abre esta carpeta en SWI-Prolog y ejecuta `?- ['ejercicio3_bd.pl'].`. Luego copia las consultas del archivo `.txt` una por una.

**Importante:** el profesor mencionó 10 tablas; el archivo entregado contiene 15. Si se permite un mínimo de 10, lo supera. Si exige exactamente 10, hay que adaptar expresamente la entrega. Las consultas de esta carpeta no se aplican automáticamente a `agencia_viajes_es_80.pl`.
